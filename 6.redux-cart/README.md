# ReduxCart

A shopping cart application built with React and Redux Toolkit, demonstrating centralized state management and asynchronous synchronization with Firebase.

### Features

* Browse a list of sample products
* Add products to the shopping cart
* Increase or decrease item quantities
* View the total quantity of items in the cart
* Calculate item totals based on quantity and price
* Persist cart data to Firebase
* Restore cart data when the application loads
* Display notifications for pending, successful, and failed requests

### Concepts

Redux Toolkit, `createSlice`, `configureStore`, React-Redux, `useSelector`, `useDispatch`, actions and reducers, custom asynchronous thunks, shared state management, asynchronous HTTP requests with Fetch API, Firebase integration, conditional rendering, and reusable UI components.
