# Food Order App

A React food ordering application that allows users to browse meals, manage their shopping cart, and submit orders through a checkout form.

### Features

* Browse available meals with images, descriptions, and prices
* Add meals to the shopping cart
* Increase or decrease item quantities
* View the cart total
* Enter customer and delivery information during checkout
* Submit orders to a backend API
* Display loading and error states
* Show order confirmation after successful submission

### Concepts

React components, Context API, `useReducer`, `useState`, `useEffect`, `useCallback`, `useContext`, custom hooks, shared state management, immutable state updates, HTTP requests with Fetch API, form handling with `useActionState`, portals, modal dialogs, conditional rendering, and error handling.
