# React Quiz App

An interactive timed quiz app built with React that tests users with multiple-choice questions and displays a summary of their performance.

### Features

* Multiple-choice questions
* Randomized answer order
* Countdown timer for each question
* Automatic skipping when the timer expires
* Visual feedback for selected, correct, and incorrect answers
* Final results summary with correct, incorrect, and skipped answer percentages
* Review of answers after completing the quiz

### Concepts

React components, `useState`, `useCallback`, `useRef`, `useEffect`, props, state management, timer management, cleanup functions, conditional rendering, derived data, and component composition.
