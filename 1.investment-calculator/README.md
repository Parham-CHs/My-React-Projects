# Investment Calculator

A simple React investment calculator that calculates yearly investment growth based on the user's inputs.

### Features

* Initial investment
* Annual contribution
* Expected return
* Investment duration
* Year-by-year results

### Concepts

React components, `useState`, controlled inputs, two-way binding, derived data, lists, and conditional rendering.
