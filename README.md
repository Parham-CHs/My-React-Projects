# React Course Projects

A collection of React projects built while following **[React - The Complete Guide](https://www.udemy.com/course/react-the-complete-guide-incl-redux/)** by Maximilian Schwarzmüller in Udemy.

The projects demonstrate my understanding of React fundamentals through practical applications.

## Projects

### Investment Calculator

An investment calculator that calculates yearly investment growth based on user input.

**Concepts:** React components, `useState`, forms, two-way binding, derived data, lists, conditional rendering.

[View Project →](./1.investment-calculator)

### Tic-Tac-Toe

A two-player Tic-Tac-Toe game with custom player names, winner detection, draw detection, and rematch functionality.

**Concepts:** State management, props, derived state, event handling, immutable updates, component composition.

[View Project →](./2.tic-tac-toe)

### Project Manager

A project management app that allows users to create projects, manage tasks, and view or edit project details.

**Concepts:** `useState`, `useRef`, props, state lifting, immutable updates, conditional rendering, component composition, portals, and imperative handles.

[View Project →](https://github.com/Parham-CHs/My-React-Projects/blob/main/3.project-manager)
