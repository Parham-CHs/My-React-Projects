# React Course Projects

A collection of React projects built while following **[React - The Complete Guide](https://www.udemy.com/course/react-the-complete-guide-incl-redux/)** by Maximilian Schwarzmüller in Udemy.

The projects demonstrate my understanding of React fundamentals through practical applications.

## Projects

### Investment Calculator

An investment calculator that calculates yearly investment growth based on user input.

**Concepts:** React components, `useState`, forms, two-way binding, derived data, lists, conditional rendering.

[View Project →](./1.investment-calculator)

### Tic-Tac-Toe

A two-player Tic-Tac-Toe game with custom player names, winner detection, draw detection, and rematch functionality.

**Concepts:** State management, props, derived state, event handling, immutable updates, component composition.

[View Project →](./2.tic-tac-toe)

### Project Manager

A project management app that allows users to create projects, manage tasks, and view or edit project details.

**Concepts:** `useState`, `useRef`, props, state lifting, immutable updates, conditional rendering, component composition, portals, and imperative handles.

[View Project →](./3.project-manager)

### Quiz App

An interactive timed quiz app that lets users answer multiple-choice questions, skip unanswered questions, and review their results when the quiz is completed.

**Concepts:** React components, `useState`, `useCallback`, `useRef`, `useEffect`, props, state management, timer management, cleanup functions, conditional rendering, and derived data.

[View Project →](./4.quiz-app)

### Food Order App

A food ordering application where users can browse available meals, add items to their cart, adjust quantities, and submit orders through a checkout form.

**Concepts:** React Context API, `useReducer`, `useState`, `useEffect`, `useCallback`, `useContext`, custom hooks, state management, HTTP requests, form handling with `useActionState`, portals, modal dialogs, and error handling.

[View Project →](./5.food-order-app)

### ReduxCart

A shopping cart application built with React and Redux Toolkit. Users can browse products, add or remove items, adjust quantities, and view cart updates. Cart data is synchronized with Firebase so the cart can be restored when the app loads.

**Concepts:** Redux Toolkit, `createSlice`, `configureStore`, React-Redux, `useSelector`, `useDispatch`, Redux actions and reducers, asynchronous thunks, HTTP requests with Fetch API, Firebase persistence, shared state management, and UI notifications.

[View Project →](./6.redux-cart)

### EventHub

An event management application built with React and React Router. Users can browse events and view their details, while authenticated users can create, edit, and delete events. The app includes login and signup flows, protected routes, and asynchronous data loading.

**Concepts:** React Router, `createBrowserRouter`, nested routes, layouts with `Outlet`, route loaders and actions, `useLoaderData`, `useRouteLoaderData`, `useNavigation`, `useFetcher`, `defer` and `Await`, form submissions, authentication, protected routes, token management, HTTP requests, and error handling.

[View Project →](./7.eventhub-app)
