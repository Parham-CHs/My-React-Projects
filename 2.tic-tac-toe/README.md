# Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with React, featuring custom player names and game state management.

### Features

* Custom player names
* Turn tracking
* Winner & draw detection
* Move history
* Rematch functionality

### Concepts

React components, `useState`, props, state lifting, derived state, event handling, immutable updates, and conditional rendering.
