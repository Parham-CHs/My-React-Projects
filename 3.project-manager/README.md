# Project Manager

A simple React project management app that allows users to create projects, manage project tasks, and view project details.

### Features

* Create new projects
* Add a project title, description, and due date
* View and select projects from the sidebar
* Delete projects
* Add tasks to projects
* Delete tasks from projects
* Validation for required project and task information
* Modal feedback for missing information

### Concepts

React components, `useState`, `useRef`, props, state lifting, immutable updates, conditional rendering, component composition, portals, and imperative handles.
