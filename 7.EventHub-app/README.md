# EventHub

A React event management application built with React Router, featuring event browsing, event management, and user authentication.

### Features

* Browse a list of events
* View individual event details
* Create new events after authentication
* Edit and delete events when authenticated
* Log in and create an account
* Protect event creation and editing routes
* Load event data through route loaders
* Submit forms through route actions
* Display loading states and handle routing errors
* Automatically log out when the authentication token expires
* Access a newsletter signup interface

### Concepts

React components, React Router, `createBrowserRouter`, nested routes, layouts with `Outlet`, route loaders and actions, `useLoaderData`, `useRouteLoaderData`, `useActionData`, `useNavigation`, `useNavigate`, `useSubmit`, `useFetcher`, `defer`, `Await`, `Suspense`, form handling, authentication, protected routes, token storage and expiration, HTTP requests with Fetch API, redirects, error handling, and CSS Modules.
